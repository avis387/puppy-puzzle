# 🐶 狗狗捉迷藏 (Puppy Puzzle) - 開發紀錄 (Changelog)

## [1.1.0] - 2026-05-13
### 新增 (Added)
- **60 關卡擴充資料片「地獄之門」**：
  - 利用 `generator.js` 演算法從 12 萬種組合中精選出 60 個具備絕對唯一解的關卡。
  - 新增 6 種難度分級：休閒、簡單、困難、高手、燒腦、地獄，並在 `index.html` 以 `<optgroup>` 下拉選單呈現。
  - 將所有關卡與解答獨立抽離至 `levels.js`，減少主程式碼體積。
- **全新「💡 解答視窗」機制**：
  - 移除原先「點擊解答直接過關」的設計。
  - 新增解答彈出視窗 (Modal)，動態生成一個縮小版的正確解答盤面供玩家參考，關閉後不影響原盤面狀態。
- **GitHub Pages 轉址與根目錄部署**：
  - 將核心遊戲檔案移至專案根目錄，以便透過 `https://avis387.github.io/puppy-puzzle/` 直接遊玩。
  - 加入 `.nojekyll` 設定以防止 GitHub Pages 編譯錯誤。

### 修正 (Fixed)
