# 狗狗捉迷藏 (Puppy Hide and Seek)

## 1. Overview
「狗狗捉迷藏」是一款單人益智解謎遊戲。玩家需要在一個 5x5 的格狀底盤上，利用 4 塊形狀各異的拼塊（包含「房子」與「路徑」兩種地形），將關卡中預先設定好的 5 隻小狗完全遮蔽在「房子」底下，同時確保「路徑」不能壓到小狗。透過旋轉、翻轉與拖曳拼塊的空間邏輯思考，玩家必須找出唯一正確的拼圖組合來過關。

## 2. Player Fantasy
我們希望玩家體驗到「拯救小動物」的溫馨感，以及「空間解謎」帶來的尤里卡效應 (Eureka moment)。視覺上採用「溫馨繪本風」，讓玩家彷彿在翻閱一本精美的童書。當玩家把最後一塊拼塊放對位置，所有小狗都順利進入溫暖的房子時，系統會給予極具療癒感的慶祝回饋，帶來放鬆且充滿成就感的體驗。

## 3. Detailed Rules
- **遊戲底盤**：5x5 網格（共 25 格）。
- **目標物件（小狗）**：每關會有 5 隻不同顏色的小狗固定在底盤上，位置不可移動。
- **操作物件（拼塊）**：共 4 塊，由「房子」與「路徑」兩種單位格子組成。總格子數為 16 格，其中剛好包含 5 個「房子」。
- **放置規則**：
  - 玩家可從待選區拖曳拼塊至底盤。
  - 單擊拼塊可將其順時針旋轉 90 度。
  - 右鍵點擊拼塊可將其水平翻轉。
- **合法性驗證**：
  - 拼塊不能重疊放置。
  - 拼塊不能超出 5x5 底盤邊界。
  - 「房子」可以蓋在空白草地或小狗上。
  - 「路徑」只能蓋在空白草地上，**絕對不能**蓋在小狗上。
- **勝利條件**：當所有 4 塊拼塊都放置在底盤上，且 5 隻小狗皆被「房子」蓋住時，判定過關。

## 4. Formulas
- **網格座標系統**：
  `Cell(r, c)` 其中 `0 <= r <= 4`, `0 <= c <= 4`。
- **拼塊碰撞偵測**：
  給定拼塊 $P$ 在座標 $(r, c)$，對於 $P$ 中的每一個非空區塊 $(pr, pc)$：
  1. 邊界檢查：$0 \le (r+pr) \le 4$ 且 $0 \le (c+pc) \le 4$
  2. 重疊檢查：$Board[r+pr][c+pc] == Empty$ (未被其他拼塊佔用)
  3. 小狗衝突檢查：若 $P[pr][pc] == Path$，則 $Board[r+pr][c+pc] \neq Dog$
- **過關檢定公式**：
  $\sum_{i=1}^{4} \text{Pieces}_i.\text{isPlaced} == 4 \land \sum (\text{House} \cap \text{Dog}) == 5$

## 5. Edge Cases
- **超出邊界釋放 (Out of Bounds)**：若玩家拖曳拼塊到一半放開，且拼塊的左上角基準點不在底盤範圍內，拼塊應具有物理彈性般地自動飛回原來的托盤位置。
- **非法放置 (Invalid Drop)**：若玩家強制將「路徑」丟在小狗上，拼塊會拒絕吸附並退回托盤。
- **旋轉導致的越界**：當拼塊已經在底盤上時，如果玩家單擊旋轉，導致旋轉後的新形狀超出邊界或壓到小狗，拼塊會自動退回托盤，避免產生卡點。

## 6. Dependencies
- **渲染系統 (Rendering System)**：Vanilla JS DOM Manipulation。
- **拖曳系統 (Drag & Drop System)**：基於滑鼠事件 (mousedown, mousemove, mouseup) 的絕對座標定位。
- **關卡資料庫 (Level DB)**：儲存預先算好的合法座標（經由 Solver 驗證）。

## 7. Tuning Knobs
- `BOARD_SIZE`：底盤尺寸（目前預設 5）。
- `CELL_SIZE`：每個格子的像素大小（影響拖曳的碰撞半徑）。
- `GAP`：格子間距。
- `INITIAL_PIECES`：拼塊形狀的定義陣列，可透過修改此陣列來改變拼圖難度。
- `LEVELS`：小狗、骨頭與大樹的初始座標設定。
- `difficultyScore`：由關卡產生器依 solver 搜索節點、合法候選數與小狗分散度計算，用於挑選更具推理負擔的關卡。
- `solverNodes` / `branchSum`：關卡驗證資料，用於確認關卡不是單純增加障礙，而是保留足夠的推理分支。

## 7.1 Difficulty Curve
- **入門**：1 個骨頭 + 1 棵大樹，避免純小狗盤面太容易被直覺破解。
- **進階**：2 個骨頭 + 1 棵大樹，開始要求玩家同時滿足路徑義務與遮蔽規則。
- **困難**：2 個骨頭 + 2 棵大樹，增加不可覆蓋格，迫使玩家排除錯誤拼塊位置。
- **高手**：3 個骨頭 + 2 棵大樹，要求玩家在更多路徑義務下規劃拼塊順序。
- **燒腦**：3 個骨頭 + 3 棵大樹，強調高限制密度與多個誘餌位置。
- **地獄**：4 個骨頭 + 3 棵大樹，保留唯一解，但讓盤面讀取與錯誤排除成本最高。
- 每一關都必須經 solver 驗證為唯一解，避免靠運氣或多解繞過設計意圖。

## 8. Acceptance Criteria
- [ ] 玩家能順暢地拖曳 4 塊拼圖，不會有游標與拼塊脫節的延遲現象。
- [ ] 點擊與右鍵能正確觸發矩陣的旋轉與翻轉。
- [ ] 只有當 5 隻小狗都被房子遮蔽時，才會觸發過關模態框 (Victory Modal)。
- [ ] 使用者介面必須呈現「溫馨繪本風」的色彩與質感。
- [ ] 關卡資料必須提供 60 關，且每關都經 solver 驗證為唯一解。
