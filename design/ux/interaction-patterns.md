# Interaction Patterns

## Overview
定義「溫馨繪本風」中的微動畫與互動手感，強調「柔軟、彈性、流暢」的物理回饋。

## Drag & Drop (拖曳互動)
- **Hover (懸停)**：當滑鼠移到拼塊上時，拼塊會稍微浮起 (`transform: translateY(-4px) scale(1.02)`)，陰影變得更柔和擴散，游標變成 `grab` (小手抓取)。
- **Active / Dragging (按住拖曳)**：拼塊進一步放大 (`scale(1.05)`)，陰影加深，給予玩家「拿起來」的真實空間感。游標變成 `grabbing`。
- **Snap (吸附)**：當玩家在底盤有效範圍內放開滑鼠時，拼塊會以清脆的彈性動畫 (`cubic-bezier(0.34, 1.56, 0.64, 1)`) 瞬間吸附到網格上，並伴隨輕微的「下壓」視覺效果。
- **Reject (拒絕放置)**：若放置位置不合法（如壓到小狗或超出邊界），拼塊會以拋物線軌跡飛回原托盤位置，或快速左右搖晃 (Shake animation) 提示錯誤。

## Click Actions (點擊互動)
- **旋轉 (單擊)**：點擊拼塊時，拼塊以中心為軸順時針旋轉 90 度，動畫時間 `0.2s`，並帶有輕微的彈跳回饋 (Overshoot)。
- **翻轉 (右鍵)**：右鍵點擊時，拼塊在 Y 軸上進行 180 度翻轉 (`transform: rotateY(180deg)`)，展現如同紙片翻面的流暢 3D 效果。

## Victory State (過關狀態)
- 當最後一個條件滿足（5隻小狗都被房子蓋住）時，延遲 `0.3s` 讓玩家看清完成的盤面，接著彈出過關模態框 (Modal)。
- **Confetti (紙片慶祝)**：模態框出現時，背景撒下溫馨色彩（粉紅、粉藍、鵝黃）的彩紙粒子特效，狗狗頭像會開心地跳躍。
- 模態框的出現動畫採用彈跳效果 (`Pop-in`)，配合圓潤的邊框與大大的笑臉圖示。
